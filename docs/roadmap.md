# Roadmap

Planned milestones:
- M1: Collect sample .sav files and produce a binary header dumper (scripts/parse_sav.py).
- M2: Write a Construct-based parser for the stable header and map tile encoding.
- M3: Implement generator that can create a valid .sav with custom width/height and basic terrain.
- M4: Build map tools to place roads, rivers, and named towns programmatically.
- M5: Create scenario data and units for 1862 and 1864 campaigns.

If you'd like, I can start working on M1 and M2 immediately once sample .sav files are uploaded.

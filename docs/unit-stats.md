# Unit Stats

This document is the starting point for Civil War unit data for the mod.

Focus areas
- Unit type: infantry, cavalry, artillery, command
- Strength, morale, movement, range
- Weapon type and firepower
- Formation and terrain modifiers
- Historical notes and campaign-era relevance

Example entry
- `union_infantry_regiment`
  - faction: Union
  - type: infantry
  - strength: 100
  - morale: 60
  - movement: 3
  - weapon: smoothbore musket

This file should grow with tables from actual historical references and game balancing notes.

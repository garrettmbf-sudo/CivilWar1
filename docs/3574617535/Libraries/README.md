# Libraries (not redistributed)

`0Harmony.dll` and `HarmonyCore.dll` were removed from this repo on 2026-10-17 because of redistribution limits. Get them from the official **HarmonyCore** mod by A Corsican Frog (Steam Workshop id **3574617535**): https://steamcommunity.com/sharedfiles/filedetails/?id=3574617535

To install, subscribe in Steam and enable HarmonyCore in Hex of Steel's mod list, above any mod that depends on it (e.g. `mods/facing`). For builds, point the facing mod's `HoSLibs` property at a local folder that holds your own copies (see `mods/facing/INSTALL.md`).

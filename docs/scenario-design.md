# Scenario Design

This file tracks the historical framing and design rules for the Shenandoah Valley campaigns.

Campaigns
- 1862: Jackson's Valley Campaign
- 1864: Sheridan's Valley Campaign

Core map features
- Valley Pike
- Shenandoah River
- Massanutten Mountain
- Blue Ridge
- Allegheny Mountains

Key towns
- Winchester
- Front Royal
- Strasburg
- New Market
- Harrisonburg
- Staunton

Design goals
- Keep the valley as a contested corridor rather than a generic battlefield.
- Distinguish strategic mobility, supply lines, and terrain advantage.
- Use historical objectives, not arbitrary win conditions.

Roadmap
- Build a campaign-level objective system.
- Encode map victory conditions in scenario JSON.
- Add Unit and command structure definitions for each campaign.

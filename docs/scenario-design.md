# Stonewall Jackson's Valley Campaign — scenario specification

**First and only release scope:** March 23–June 9, 1862, from First Kernstown through Port Republic. Both Union and Confederate play must be possible; battles arise from maneuver, not fixed wins.

## Map
- Target one **geographic mile per hex**, measured consistently in the Hex of Steel map projection.
- Main Shenandoah Valley must allow multiple brigades alongside the Valley Pike. A brigade must not block the valley by itself.
- Separate Massanutten Mountain and Luray Valley. Include New Market Gap and other period-appropriate connecting routes.
- Boundaries must include Winchester–Staunton and the Front Royal/Luray and McDowell/Franklin approaches.
- Trace **1862** towns, rivers, roads, crossings and western mountain routes from documented sources rather than modern roads.

## Combat formations
- Use independently movable **brigade** counters for primary infantry; attached artillery and cavalry at historically reasonable granularity.
- Parent command reflects **actual organization by date**. Johnson's force joins after McDowell; Ewell's troops join later; Shields' department attachment changes.
- Do not invent 1863-style Confederate corps for the 1862 Valley Army.
- Unit strengths and command ranks have dated sources; unverified figures are flagged.

## Operational tests
1. Multiple columns can use the Pike and alternate roads.
2. One division can deploy across the main Valley without artificially saturating it.
3. Separate forces can march on each side of Massanutten and use genuine gaps.
4. Cavalry can scout and screen alternative routes.
5. Defensible bottlenecks remain defensible, without static walls extending everywhere.
6. The Union can concentrate and beat Jackson; victories and defeats must not be scripted.
7. Game turn processing and save/load with plausible unit counts remain acceptable.

## Planned engagements
First Kernstown (Mar 23), McDowell (May 8), Front Royal (May 23), First Winchester (May 25), Cross Keys (Jun 8), Port Republic (Jun 9), plus intervening marches and historical reinforcements.

No 1864 scenarios or national-war mechanics in this run.

# Active campaign: Jackson's 1862 Shenandoah Valley

This is the **only active scenario development period**.

Goals:
1. Use a geographically accurate one-mile-per-hex Valley map (subject to tested engine constraints).
2. Allow historically placed **brigade** counters, artillery, cavalry and their visible commanders.
3. Represent Jackson/Ewell/Johnson and Banks/Shields/Frémont as separate historically dated organizations.
4. Preserve Hex of Steel's direct counter controls.
5. Support a campaign from Kernstown through Port Republic, including reinforcements and alternate outcomes.

**Current status:** scenario specifications only. No verified playable scenario claimed.

Acceptance tests and historical requirements are in `docs/scenario-design.md`.

# Reference materials and existing portraits

This directory contains **reference-only** source material, historical images, and some audited officer portraits. Do not delete or rename known portraits without checking all game consumers.

Relevant images:
- `Stonewall in the ValleyMap.jpg` — campaign board map used as a **visual and geographic reference**, not automatically distributable map art.
- `SJW IIMap.jpg` — additional historical/game map reference; origin and reuse rights must be recorded.
- `mdl_USA_*.png` — existing Union portrait art (retain approved filenames).
- `mdl_CSA_*.png` — additional Confederate art, e.g. `mdl_CSA_JAWalker.png`.
- `General Portraits` — existing archived/reference item; inspect before repackaging.

Record licensing and source metadata in `source_register.csv`. Unknown provenance means **reference only**, not permission to redistribute.
